# OpenCapture 📸

> **Free and Open-Source (FOSS) full-page webpage screenshot & annotation extension.**  
> Zero paywalls, zero ads, zero telemetry, 100% local-first.

---

## 🌟 Highlights

- ⚡ **Full Page & Scrollable Capture:** Capture entire scrollable containers and lengthy pages without manual scrolling.
- 🔍 **2x HD Screenshots:** High-DPI capture for crisp text, vectors, and layouts.
- ✂️ **Ultra-Long Page Split:** Automatically splits massive web pages into logical segments for clean export.
- 🎨 **Powerful Annotation & Editing:** Built-in tools for rectangles, callouts, arrows, text, freehand drawing, and mosaic/blur.
- 🗂️ **Local Screenshot History:** Fast IndexedDB storage to revisit and re-export past captures without limits.
- 📄 **Flexible Export Options:** Copy to clipboard, save as PNG/JPEG, or generate high-quality multi-page PDFs.
- 🔒 **Privacy First:** No tracking, no external server calls, no telemetry. Everything runs inside your browser sandbox.

---

## 📦 Installation (Load Unpacked / Developer Mode)

### Google Chrome / Chromium / Brave
1. Clone or download this repository:
   ```bash
   git clone https://github.com/nklowns/opencapture.git
   ```
2. Navigate to `chrome://extensions` in your browser.
3. Enable **Developer mode** in the top right corner.
4. Click **Load unpacked** and select the `opencapture` directory.

### Microsoft Edge
1. Navigate to `edge://extensions`.
2. Enable **Developer mode** in the lower-left sidebar.
3. Click **Load unpacked** and select the `opencapture` directory.
